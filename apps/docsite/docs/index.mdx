# shadcn-semi-design

**shadcn/ui 的 API 架构 + Semi Design 的 1:1 视觉语言**。基于 Base UI 原语,64 个组件;全部视觉值取自 Semi Design 默认主题 token,light/dark 随 `.dark` 类整体反转。

环境要求:React 18/19、Tailwind CSS v4、Node.js ≥ 20。

```bash
pnpm add shadcn-semi-design
```

在应用全局 CSS 中引入(Tailwind 必须在前):

```css
@import "tailwindcss";
@import "shadcn-semi-design/styles";
```

- 原始色板在暗色下整体反转色阶;语义 token 随之联动
- shadcn 映射:`--primary` → `--semi-color-primary`、`--muted` → `--semi-color-fill-0`、`--destructive` → `--semi-color-danger`
- 圆角 3px(控件)/ 6px(弹层)/ 12px(大容器);控件高度 24/32/40px;正文 14px/20px、字重 600

```tsx
// 暗色切换:换 token 值而非换类,组件无需 dark: 前缀
document.documentElement.classList.toggle("dark");
```
